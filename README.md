◉ The person behind the code
I'm Ayodeji (Deji) — a software engineer and product builder who enjoys turning messy problems into clear, usable experiences. I care about the details users feel, the architecture developers maintain, and the product decisions that connect both.
- I build: web apps, mobile experiences, dashboards, APIs, and early-stage products.
- I value: thoughtful UX, maintainable architecture, performance, and shipping useful things.
- Currently exploring: AI-powered product experiences and better ways to build in public.
Good software isn't just code that works. It's a problem understood well enough to solve elegantly.

<details>
  <summary><strong>How I like to build</strong></summary>

- Start by asking why and clarifying the real user problem.
- Make the main flow easy to understand before adding complexity.
- Keep boundaries clear between UI, business logic, data access, and integrations.
- Treat loading, empty, error, and success states as part of the product.
- Document decisions so the next person can understand not only what changed, but why.</details>
